# App icon

`AppIcon.png` is the WorkBuddy image used at the top of the project README,
downloaded without modification from:

https://raw.githubusercontent.com/DGZSbot/ai-icon/refs/heads/main/WorkBuddy.png

Run `bash scripts/macos/build-icon.sh` from the repository root to regenerate
`AppIcon.icns`. The source PNG is stored locally so builds do not depend on
the remote image being available.
